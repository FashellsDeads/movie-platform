> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** В CineVibe выполнить ДЗ №12 (паттерны компонентов), №13 (формы, ref, reducer) и №14 (сайт становится единым «Online Store» кинотеатра). Каждое ДЗ сдаётся своим коммитом и меткой.

- **№12 и №13** добавляют переиспользуемые компоненты и демо-страницы `/patterns` и `/form-builder` в текущую плоскую структуру `src/components/<Name>/`.

### Task 9: formReducer, история Undo/Redo, валидация полей

**Files:** Create `src/components/FormProvider/formReducer.js`, `src/utils/formValidation.js`. Tests `formReducer.test.js`, `src/utils/formValidation.test.js`.

**Interfaces (Produces, используются в Tasks 10–11 и в hw14):**
- `FORM_ACTIONS = { ADD_FIELD, REMOVE_FIELD, UPDATE_FIELD, UPDATE_VALUE, RESET_FORM, SET_ERRORS, UNDO, REDO }` (строки с теми же именами).
- Тип поля: `{ id: string, name: string, label: string, type: 'text'|'email'|'number'|'select'|'password'|'checkbox'|'radio', required: boolean, options?: Array<string | { value, label }>, placeholder?: string }`.
- `createFormState(fields, values = {})` → `{ fields, values, errors: {} }`. Для каждого поля без значения ставится `''`, для `checkbox` — `false`.
- `formReducer(state, action)`. Payload'ы:
  - `ADD_FIELD {field}`;
  - `REMOVE_FIELD {id}` — удаляет поле и его value/error;
  - `UPDATE_FIELD {id, changes}` — при смене `type` value поля сбрасывается;
  - `UPDATE_VALUE {name, value}` — убирает ошибку этого поля;
  - `RESET_FORM {initialState}`;
  - `SET_ERRORS {errors}`.
  - Неизвестное действие возвращает тот же state.
- `withHistory(reducer)` → `(history, action) => history`, где `history = { past: State[], present: State, future: State[] }`.
  - `ADD_FIELD`/`REMOVE_FIELD`/`UPDATE_FIELD`: `past = [...past, present]`, `future = []`, но только если новый present !== старый.
  - `UNDO`/`REDO` двигают между стеками.
  - `RESET_FORM`: `past = []`, `future = []`.
  - Остальные действия меняют только present.
- `createHistory(state)` → `{ past: [], present: state, future: [] }`.
- `validateField(field, value): string`. Сообщения:
  - пустое обязательное — `'Обязательное поле'`, для checkbox — `false`;
  - email не по `EMAIL_PATTERN` из `utils/validation.js` — `'Введите корректный email'`;
  - number: `Number.isFinite(Number(value))` ложно — `'Введите число'`;
  - пустое необязательное поле не проверяется.
- `validateFields(fields, values): Record<name, string>` — только непустые ошибки.

  - по одному на каждое действие reducer;
  - `сценарий из задания`: add → change label → delete → undo → undo → redo. Сверить `fields` после каждого шага;
  - `undo после reset ничего не делает`;
  - `новое изменение после undo очищает future` (Review Focus 5);
  - `UPDATE_VALUE не попадает в историю`;
  - валидация: `'' required → Обязательное поле`, `'abc' email → Введите корректный email`, `'12a' number → Введите число`, `'' необязательный email → ''`.
